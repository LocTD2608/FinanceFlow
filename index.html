📦 Cách Đưa Chiikawa Mascot Vào App Của Bạn

Mascot đã được đóng gói thành SDK JavaScript độc lập (chiikawa-mascot.js). Thành viên trong team chỉ cần nạp tệp này và gọi các lệnh AI:

1. Nhúng thư viện vào web:
<script src="chiikawa-mascot.js"></script>
2. Khởi tạo mascot:
const mascot = new ChiikawaMascot({ container: '#my-chat-container', // hoặc mode: 'floating' size: 260 });
3. Điều khiển phản xạ AI:
// Khi người dùng bấm gửi tin nhắn: mascot.think("Đang suy nghĩ câu trả lời..."); // Khi đang gọi API AI: mascot.load(); // Khi có câu trả lời: mascot.answer("Đây là câu trả lời của AI!"); // Khi gặp lỗi: mascot.error("Không thể kết nối máy chủ!");

📁 Xem thêm code mẫu React (examples/react-example.jsx) và Vue (examples/vue-example.vue) trong repository!
